# Что показал прогон BPI Challenge 2012

Запуск прочитал весь файл `BPI_Challenge_2012.xes.gz` версии 1: 262 200
событий, 13 087 traces, 24 действия, 4 366 вариантов и 125 directly-follows
переходов. Все события содержали case id, activity и timestamp, поэтому parser
не пропустил ни одной записи по обязательным полям.

| Показатель | Результат |
| --- | ---: |
| Время чтения XES | 6.270 с |
| Полный анализ | 10.235 с |
| Peak Python allocations (`tracemalloc`) | 231 545 971 bytes |
| Длительность case p50 | 69 857.434 с, 0.809 суток |
| Длительность case p90 | 2 631 876.989 с, 30.462 суток |
| Длительность case p95 | 2 708 077.560 с, 31.343 суток |
| Cases с повтором действия | 9 658, 73.798% |

Наиболее частый вариант `A_SUBMITTED → A_PARTLYSUBMITTED → A_DECLINED`
встретился в 3 429 cases, или 26.202%, и имел p95 53.738 секунды. Его нельзя
использовать как утверждённую эталонную BPMN: это просто наиболее частая
наблюдаемая последовательность в файле. Поэтому расхождения с ним не являются
ошибками процесса и не используются как рекомендация менять операции.

В ranking ожиданий исключены переходы реже 100 раз. Самый высокий p95 среди
оставшихся у `W_Completeren aanvraag → W_Nabellen offertes`: 704 616.172
секунды, или 8.155 суток, при 5 015 переходах. Это место для дальнейшего
разбора причин, а не доказательство, что задержку вызвало конкретное действие.

В файле много self-loops и возвратов, поэтому 9 658 cases содержат повторное
действие. Автоматический score намеренно не интерпретируется как ROI: он лишь
ранжирует последовательности по частоте, разбросу длительности, длине пути и
статистическому baseline.

Все числа и полный список top variants, переходов, deviations и scores находятся
в [results.json](../studies/bpi-challenge-2012-2026-08-10/results.json). Источник,
точная версия и hash находятся в
[source-manifest.json](../studies/bpi-challenge-2012-2026-08-10/source-manifest.json).
